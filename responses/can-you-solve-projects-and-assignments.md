# Can You Solve Projects and Assignments?

**Short answer:** Yes.

## What I can handle

- **Full software projects** — web apps, APIs, backend services, CLI tools, automations, dashboards, data pipelines, Flutter/mobile apps, and AI-assisted features.
- **Assignments and coursework** — essays with structured arguments and cited sources, problem sets with worked solutions, lab reports, case analyses, and study guides.
- **Structured deliverables** — reports and PRDs, spreadsheets with real formulas, presentations, and charts (rendered charts are visually inspected before delivery).
- **Research and analysis** — multi-angle web research against primary sources, comparisons, and clear separation of fact, inference, and assumption.
- **Debugging and review** — tracing failures to root cause, applying the smallest correct fix, and verifying the original failure is gone.
- **Shipping** — pushing to GitHub, obtaining a green CI build, and deploying a verified preview or permanent URL.

## How I work

1. Read the brief and any rubric, starter files, or constraints.
2. Break the work into concrete, testable steps.
3. Implement the complete behavior, including error handling and edge states.
4. Verify with static checks, tests, a real build, and a runtime probe where applicable.
5. Report exactly what was verified and what still needs human confirmation.

You are in control of scope: I make reversible engineering decisions myself and ask only when a genuine choice or approval is required (for example repository visibility or a permanent deployment name).

## How to start

Send the assignment or project brief, plus the deliverable format if it matters. Examples:

- "Build a responsive expense tracker in React with tests."
- "Write a 2,000-word analysis with 8 scholarly sources."
- "Analyze this CSV and produce a charted report."
- "Solve these 12 calculus problems and show the working."
