Question One 
 
Rules 
1. Draw each node as a box, as in the "Putting it All Together" slide: the kind on top, its fields 
below. Draw an arrow from a field to the node it points to. An empty field is NULL. 
2. Statements are linked through next. 
3. A local declaration is a STMT_DECL whose decl points to a DECL. The initial value goes 
in the DECL's value. 
4. STMT_IF_ELSE uses expr (condition), body and else_body. Each { } branch is a 
STMT_BLOCK whose body points to its statement. STMT_PRINT and STMT_RETURN 
use expr. 
5. A call is an EXPR_CALL: left is the function name, and right is a chain of EXPR_ARG 
nodes. Each EXPR_ARG holds one argument in left and the next EXPR_ARG (or NULL) in 
right.

Question Three 
 The symbol table stores one entry for every name declared in a program. Each entry 
records: 
• Kind: GLOBAL (declared outside any function), PARAM (a function parameter) or 
LOCAL (a variable declared inside a function). 
• Which: the position number. Parameters are numbered 0, 1, 2 … in order. Locals 
are numbered 0, 1, 2 … in order, starting again from 0 in each function. Globals have 
no number (write –). 
• Type: the declared type of the name. 
• Scope: where the name is visible: Global, or the name of the function it belongs to.
